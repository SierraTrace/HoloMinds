# HoloMinds
In this project, five micro-games (2D or 3D) will be created as part of an individual or team competition. Each micro-game will contribute points to the final score based on the player's performance.

Of these micro-games, at least one must be an AR game and one a VR (mobile) game. The remaining games will be played on a mobile device with an interaction designed by each team for each game.

The complete development process includes designing the micro-games and documenting them in a wiki-based Game Design Document (GDD), which will include multimedia content. Additionally, a functional and performance testing plan will be developed, and the results will be recorded to identify potential bugs and bottlenecks.
